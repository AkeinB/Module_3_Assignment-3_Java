# Vocational Training Development Institute
This project is an assignment for the Vocational Training Development Institute, School of Applied Technology, Department of ICT.
It focuses on building a Java Swing GUI Application, applying Object-Oriented Programming principles such as the Model-View-Controller (MVC) pattern, exception handling, and file persistence.
